# Financefy

**Financefy** is a web application designed to help you track your income and expenses efficiently. Built with React and Vite, it offers a seamless user experience for managing personal finances.

🔗 **Live Demo**: [financefy.vercel.app](https://financefy.vercel.app)

---

## 🚀 Features

- **Income & Expense Tracking**: Easily log your financial transactions.
- **Real-time Updates**: Experience instantaneous updates with Vite's Hot Module Replacement (HMR).
- **Modern UI**: Enjoy a clean and intuitive user interface built with React.
- **Deployment**: Hosted on Vercel for fast and reliable access.

---

## 🛠️ Tech Stack

- **Frontend**: React, Vite
- **Deployment**: Vercel
- **Version Control**: Git, GitHub

---

## 📦 Installation

To run Financefy locally, follow these steps:

1. **Clone the repository**:

   ```bash
   git clone https://github.com/Kuntal616/Financefy.git
   cd Financefy
   ```

2. **Install dependencies**:

   ```bash
   npm install
   ```

3. **Start the development server**:

   ```bash
   npm run dev
   ```

4. **Access the application**:

   Open your browser and navigate to `http://localhost:5173` to view the app.
